
# ShipEasy - Shipping Cost Calculator

## About the Project
ShipEasy is a simple and user-friendly Shipping Cost Calculator website.
It helps users estimate the delivery charges of a parcel based on its
weight, package type and delivery speed.

## Features
- Enter pickup location.
- Enter delivery location.
- Calculate shipping charges based on package weight.
- Select different package types.
- Choose Standard or Express delivery.
- Display estimated delivery time.
- Show total shipping cost instantly.

## How to Run the Project

1. Download or clone the project.
2. Open the project folder in VS Code.
3. Open index.html in your browser.
4. Enter the shipping details.
5. Click on Calculate Shipping.
6. View the estimated shipping cost.

## Calculation Method

Base Charge = ₹50

Weight Charge = Weight × ₹30

Package Charge:
- Document = ₹0
- Small Parcel = ₹20
- Large Parcel = ₹50

Express Delivery = 1.5 × Standard Cost

Total Cost = Base Charge + Weight Charge
             + Package Charge
